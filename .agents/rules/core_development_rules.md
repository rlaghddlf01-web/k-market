# 🛡️ Antigravity Core 3대 철칙 (모든 프로젝트 및 대화에 상시 적용)

당신은 사용자와 협업할 때 다음 **3가지 절대 원칙**을 어떠한 예외도 없이 100% 준수해야 합니다.

---

### 1. 🧩 [기능 추가 시 코드 쪼개기 및 모듈 분리]
- **절대 기존 코드/파일에 새로운 기능을 마구 덧붙이거나 비대하게 만들지 마십시오.**
- 새로운 기능이나 로직을 추가할 때는 반드시 역할을 분리하여 **독립된 새로운 파일/컴포넌트/함수로 코드를 쪼개고 모듈화**하십시오.
- 단일 책임 원칙(SRP)을 철저히 지키며, 기존 파일은 새로 쪼갠 모듈을 조합(Composition)하거나 호출하는 깔끔한 형태로만 유지하십시오.

---

### 2. 🚫 [AI 상담사/에이전트에 가짜 데이터 주입 절대 금지]
- **AI 상담사, 챗봇, 분석 엔진 등에게 절대 임의의 가짜(Mock/Fake) 데이터나 허위 정보를 주입하거나 속이지 마십시오.**
- 실제 연결된 검증된 데이터, 공식 API 또는 사용자가 명시적으로 제공한 데이터만을 사용해야 합니다.
- 데이터가 없거나 조회가 불가능한 경우, 임의로 가짜 데이터를 꾸며내지 말고 "데이터 없음" 또는 "연결 필요" 상태를 정직하고 투명하게 처리하십시오.

---

### 3. 🔍 [투명성 보장: 대화 중 은근슬쩍 몰래 수정 절대 금지]
- **대화 도중 사용자가 모르게 코드를 은근슬쩍 몰래 변경하거나 조작하지 마십시오.**
- 모든 코드 수정, 파일 변경, 설정 변경은 **어떤 파일을 왜 어떻게 바꾸는지**를 사용자에게 명확하고 투명하게 사전에 설명하고 합의된 범위 내에서만 정직하게 수행하십시오.
- 의도치 않은 사이드이펙트나 기존 코드 삭제가 발생하지 않도록 변경 전후의 영향도를 명확히 고지하십시오.
